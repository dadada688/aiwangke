# 学习通 · AI智脑Pro（视频弹题修复版）

一个运行在浏览器里的用户脚本（Userscript），用于辅助学习通章节视频播放与答题。
本仓库基于 [Z-Fovik-RT/chaoxing-ai](https://github.com/Z-Fovik-RT/chaoxing-ai) 修改，采用 MIT License，保留原作者署名。

- 脚本直链（安装地址）：`https://raw.githubusercontent.com/dadada688/aiwangke/main/chaoxing-ai.user.js`
- 仓库地址：`https://github.com/dadada688/aiwangke`

## 一、这个版本改了什么

在原作者版本的基础上，本仓库做了以下四项改动：视频弹题的答案匹配、弹题答错后的重试提交、播放器网络错误的线路自动切换、前面未完成任务点的回补。其余功能与原版一致。

### 1. 答案匹配更宽松

弹题选项通常带有 `A、` `B、` 这类前缀，原版要求「选项文字」与「AI 返回的答案」完全相等，很容易匹配失败。
现在会：

- 去掉选项前缀再匹配；
- 支持 AI 只返回字母（`A`、`B`、`C`）的情况；
- 支持模糊/相似度匹配；
- 支持判断题（对/错、正确/错误）的解析。

### 2. 答错自动换选项再提交

学习通弹题的规则是：答错之后提交按钮会失效，必须先换一个选项才能再次提交。
本版本的流程是：

1. 选中答案 → 点提交；
2. 如果提示「回答错误」，或者提交后弹题仍然没有通过；
3. 自动换下一个选项 → 再点提交；
4. 重复直到提交通过，最多 8 次或所有选项都试过为止。

目的是**让弹题能顺利提交、不卡住视频**，不追求正确率。
同一道题已经试过的选项会被记住，避免页面重绘后反复提交同一个错误答案。

### 3. 视频网络错误自动切换线路

播放器有时会提示：

> 网络错误导致视频下载中途失败。您可以尝试其他线路：公网1 / 公网2 / 本校

出现这个提示时视频会卡住不动。脚本会每 4 秒检查一次，检测到该提示后自动点下一个线路：

- 顺序：公网1 → 公网2 → 本校，全部试过后重新轮换；
- 切换后等待播放器重建，重新接管播放并恢复倍速；
- 同一条线路不会在 4 秒内重复点击。

### 4. 回补前面未完成的任务点

有时前面的章节因为视频加载失败、网络中断被跳过，目录里还留着“待完成”标记（比如 20.6），但脚本已经跑到后面的 20.7。
现在每次准备进入下一章之前，会先检查目录中**当前章节之前**有没有未完成项：

- 有，就自动返回该任务点补刷；
- 每个任务点最多回补 2 次，避免某章反复失败导致死循环；
- 找不到对应的目录节点时，记录日志并继续向后处理。

### 5. 没改的部分

章节测验、考试、视频倍速、字体解密、章节自动导航、粘贴限制绕过等功能**保持原版逻辑**，一行未改。

## 二、安装方法（详细步骤）

### 第 1 步：安装用户脚本管理器

任选其一：

- **Tampermonkey（推荐）**：<https://www.tampermonkey.net/>
- **ScriptCat 脚本猫**：<https://scriptcat.org/>

在 Edge 里安装时，如果提示「允许来自其他应用商店的扩展」，需要先允许，再安装。
安装完成后，浏览器右上角会出现 Tampermonkey 图标（拼图图标里可以固定显示）。

### 第 2 步：安装本脚本

**方法 A：直接打开安装地址**

在浏览器地址栏打开：

```
https://raw.githubusercontent.com/dadada688/aiwangke/main/chaoxing-ai.user.js
```

Tampermonkey 会弹出「安装用户脚本」页面，点 **安装**。

**方法 B：从仓库安装**

1. 打开仓库 <https://github.com/dadada688/aiwangke>
2. 点击列表里的 `chaoxing-ai.user.js`
3. 点右上角的 **Raw** 按钮
4. Tampermonkey 弹出安装页，点 **安装**

> 如果打开 Raw 后只看到一堆代码、没有弹出安装页，说明 Tampermonkey 没装好或没启用，回到第 1 步检查。

### 第 3 步：确认安装成功

1. 点击浏览器右上角 Tampermonkey 图标 → **管理面板**
2. 在「已安装脚本」里应该能看到 **学习通 · AI智脑Pro**，版本 `1.3.14.4`
3. 只保留**一个**同名脚本，重复安装会导致脚本执行两次

### 第 4 步：进入学习通

1. 打开并登录学习通网页版，进入课程 → 章节学习页面
2. 页面右下角会出现脚本的悬浮球
3. 如果看不到悬浮球，刷新一次页面

## 三、配置 AI（必须做，否则无法自动答题）

脚本本身**不带** AI Key，需要自己准备。

1. 在脚本面板里点 **模型**；
2. 选择接口服务商，例如 `deepseek`；
3. 选择模型，例如 `deepseek-chat`；
4. 填入自己的 API Key；
5. 保存，并把该模型设为**第一优先级**；
6. 需要时点 **检测** 验证 Key 是否可用（会把 Key 发送到对应服务商）。

常见可选项：

| 服务商 | 说明 |
| --- | --- |
| DeepSeek | 便宜、中文好，需要自己注册并充值 |
| 通义千问 / Qwen | 阿里云百炼平台 |
| 自定义 Provider | 面板里可自行添加 OpenAI 兼容接口 |

注意：

- API Key 只保存在浏览器本地，不会写进代码，也不会随仓库分发；
- AI 调用产生的费用由使用者自行承担；
- 题库类功能（N1 搜题、大学搜题酱等）需要各自的 Token，是否可用取决于第三方服务。

## 四、使用方法

1. 进入章节页面后，脚本会自动开始处理视频；
2. 视频按设定倍速播放，任务点会逐步变成已完成；
3. 视频中途弹出题目时，脚本会自动作答：
   - 先尝试题库/AI 给出的答案；
   - 答错会自动换选项重试，直到提交通过；
4. 章节测验会按原版逻辑自动作答并提交（本次未改动）。

面板上的常用开关：

- 悬浮球上的 **⏸ / ▶**：暂停或继续脚本的所有刷课与答题任务；
- **设置**：倍速、答题间隔、是否自动提交测验等；
- **日志**：查看每一步执行记录，排查问题看这里。

## 五、常见问题

**Q：页面右下角没有悬浮球？**
A：刷新页面；或在 Tampermonkey 管理面板确认脚本已启用、且当前网址匹配 `*.chaoxing.com`。

**Q：弹题出现了但没有任何动作？**
A：先看「日志」。如果是「未匹配到答案」，检查模型配置；如果是请求失败，检查 API Key、余额和网络。

**Q：视频一直卡住不继续？**
A：弹题没提交成功时视频会等待。看日志里是否有「多次提交仍未通过」，这种情况通常是题目本身或网络问题，可以手动点一下。

**Q：出现“网络错误导致视频下载中途失败”怎么办？**
A：不用管，脚本会自动切换线路（公网1 → 公网2 → 本校）并恢复播放。如果三个线路都失败，日志里会有多次切换记录，这时多半是视频源本身有问题，可以稍后再试。

**Q：前面的章节显示“待完成”，脚本却跑到后面去了？**
A：新版本会在进入下一章之前回头补刷前面的未完成项，每个最多回补 2 次。如果某个章节连续失败，会保留记录并继续向后处理，不会卡死。

**Q：章节测验会不会也被自动提交？**
A：会，但走的是原版逻辑，本次修改只影响视频弹题。

**Q：脚本会不会自动更新成原作者的版本？**
A：不会。`@updateURL` 已指向本仓库，只有本仓库更新时才会提示更新。
